# Nassau Candy Product Line Profitability & Margin Performance Analysis

## Project Overview
This project analyzes product-level profitability, gross margin performance, and division-wise financial efficiency for Nassau Candy Distributor using Python and Streamlit.

## Features
- Interactive Streamlit Dashboard
- KPI Cards (Sales, Profit, Units, Margin)
- Division Filter
- Date Range Filter
- Product Search
- Sales by Division
- Profit by Region
- Monthly Sales Trend
- Top Product Analysis
- Cost vs Profit Analysis
- Download Filtered Data

## Tools Used
- Python
- Pandas
- Plotly
- Streamlit
